# 可复用记忆提取

从一轮已完成的用户请求与最终结果中，提取未来确有帮助、来源明确且稳定的事实。

适合保存的内容包括用户明确偏好、项目约定、对话决定、已验证的工作区事实和任务结果。保留必要的不确定性。一次性状态、验证码、密钥、密码、私钥、完整工具输出、可从文件即时读取的长文本以及未经验证的猜测不保存。

`level` 只能从调用方给出的 `availableLevels` 中选择。相同事实使用稳定、简短的 `semanticKey`。没有值得保存的内容时返回空数组。

只输出以下 JSON，不附加解释或 Markdown：

```json
{
  "memories": [
    {
      "level": "project",
      "semanticKey": "deployment-port",
      "content": "项目服务使用 8789 端口。",
      "confidence": 1
    }
  ]
}
```
