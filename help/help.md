# EasyWork 使用帮助

**EasyWork** 是一个把日常大模型对话与远程服务器工作流放在同一页面中的浏览器应用。您不仅可以直接聊天，也可以在已连接服务器的工作区中使用 **Agent** 执行任务。使用电脑、手机或平板等任一能够打开网页的设备登录 EasyWork，同一账号即可共享所有对话和远程服务器配置。

## 1. 登录

1. 点击左下角的个人资料，使用**用户名**和**密码**注册或登录。用户名至少需要 2 个字符，密码至少需要 8 个字符。登录后，服务器配置、模型 API、对话和其他个人数据都会保存在您的账户中；在其他设备登录同一账号依旧有效。
2. 未登录时将以游客身份访问。注册、登录或主动退出访客会话后，当前游客数据会被安全清理；长期未使用且没有任务或服务器配置的游客数据也会定期回收。

## 2. 配置模型 API

1. 打开菜单栏下方个人资料中的“**模型 API**”，新建或选择一个 API 配置，填写 **API 名称**、**API URL** 和 **API Key** 后保存。API 名称可由您自行决定。保存后，您既可以在网页聊天中使用该 API，也可以用它配置服务器上的 Agent。
2. 如果您没有配置 API，可以在模型列表中选择网页官方提供的 API。若列表中没有该选项，说明平台部署方当前没有为此平台提供 API。

## 3. 对话

### 聊天模式

与其他大模型网页对话一样，在新对话页选择“**聊天**”，从输入框中选择要使用的模型，输入问题并发送。您还可以点击加号添加相关技能，通过与聊天模式的大模型对话，了解如何利用工作模式为您提供服务。

### 工作模式

工作模式可以让您直接控制远程服务器上的 Agent 工作。整个过程中，任务执行和问题回答都由该 Agent 所使用的大模型决定；您可以在 Agent 配置中选择该 Agent 使用的大模型。

新建工作模式对话后，依次完成下面三项准备，即可发送任务：

#### 1. 连接服务器

此项决定要连接哪台服务器。您需要填写**服务器名称**（由您自行决定，供网页显示）、**服务器地址**、服务器账号及密码（或密钥）；连接时是否需要 **2FA 验证码**，由目标服务器决定。您也可以通过左侧菜单栏中的“远程服务器”管理服务器配置。

#### 2. 配置 Agent

此项决定在服务器上使用哪个 Agent 工作。连接成功后，点击“**配置 Agent**”。您可以让 EasyWork 自动部署 Agent，目前支持 **OpenCode**、**Claude Code** 和 **Codex**；也可以手动选择服务器上已有的 Agent，但 EasyWork 无法调整用户自行部署 Agent 的权限和 API 等配置。

在对话过程中，您可以随时切换不同的 Agent。关键记忆全部保留在 EasyWork 中，无需担心切换 Agent 后丢失记忆。

#### 3. 选择工作区

此项决定服务器上的 Agent 在哪个目录中工作。Agent 可以自动查询工作区内的全部内容；查看工作区之外的内容时，可能需要您额外指定。创建的文件通常也会位于工作区内，Agent 在该目录中的可用权限一般更高。对话过程中，您可以随时在右侧功能栏切换工作区，EasyWork 已对这些情况进行适配。

工作区分为两种：**虚拟工作区**和**用户工作区**。虚拟工作区由 EasyWork 自动创建在服务器的 `.easywork` 目录中，适合查询和临时任务；用户工作区则会把您指定的服务器文件夹作为 Agent 的工作目录。

#### 4. 进行对话

完成服务器、Agent 和工作区设置后，在输入框中描述并发送您想完成的任务即可开始工作。除此之外，您可以回溯到任意对话记录，删除该记录之后产生的全部由Agent造成的文件改动和相关记忆；也可以在任意对话记录处创建分支，并继承此前的全部记忆。在整个对话过程中，您可以随时切换工作区、远端Agent等，相关记忆会同步发送给新的远端Agent对话。

## 4. 文件和技能

**关于文件**，您可以在文件库中新建文件集，向文件集中添加您想上传的内容，使用时，只需要在对话输入框左侧的加号中选择关联文件集，网页Agent会自动根据您的提问查找文件集中的相关内容。您也可以在项目中上传文件或者关联文件集，项目中的所有对话都会默认检索项目自带的文件内容或者关联的文件集内容。

**关于技能**，默认给每位用户配置了一些关于本科生算力平台的初始内容，您也可以在技能市场中安装您感兴趣的技能，安装后无需额外操作，网页Agent会自动根据您的提问查找相关技能。如果您希望修改技能的应用范围，可以点开技能详情页，并在标题下方的按钮处修改，可以设置为仅聊天/工作模式可用，也可设置为仅特定服务器可用。
